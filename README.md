# Jogo-Humanos-VS-Orcs
Jogo de batalha em C++ desenvolvido para a disciplina de Linguagem de Programação II da Universidade Federal de Santa Catarina. O projeto simula um combate entre dois exércitos: Humanos e ORCs, utilizando programação orientada a objetos, vetores, arquivos de texto e geração aleatória de atributos.
